<h2 id="about-the-project">About Challenge 11 (Interactive Image Slideshow)</h2>

This branch contains 3 tasks in one .js document. <br>

- Task 1 (Change Images) - Setting up the HTML document with buttons that allow to change between images by clicking on them.
  <br>
- Task 2 (Disable Actions) - Disabling the "Previous" button when viewing the first image from the gallery and disabling "Next" button when viewing the last image from the gallery. <br>
- Task 3 (Keyboard Events) - Adding event listeners to change the images by pressing the arrow left and arrow right keys on the keyboard.
